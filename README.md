# Zentime Ajay

Current source code for the Zentime backend, Admin Web, Mobile App, and Super Admin.

## Projects

- `backend` - Spring Boot backend
- `admin` - React Admin Web
- `mobile-app` - Expo React Native app
- `super-admin` - Super Admin web application

Environment-specific credentials, build artifacts, runtime logs, uploads, and signing files are intentionally excluded from version control.
